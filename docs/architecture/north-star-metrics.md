# 北极星指标

**当前版本**: 0.1.0
**更新日期**: 2026-08-04

---

## 概述

北极星指标是衡量 AutoHarness 项目成功的核心指标。所有 AI 决策和开发工作都必须围绕这些指标展开。

---

## 核心指标

### 1. 代码合成成功率 (Synthesis Success Rate)

| 属性 | 值 |
|------|-----|
| 定义 | 成功合成的测试用例数 / 总请求数 |
| 测量方法 | 统计 `synthesis` 命令执行结果 |
| 当前目标 | ≥ 85% |
| 现状基线 | 待测量 |

**改进方向**:
- 优化 LLM prompt 模板
- 增加更多合成策略
- 改进错误处理和回退机制

---

### 2. 平均合成时间 (Average Synthesis Time)

| 属性 | 值 |
|------|-----|
| 定义 | 单次合成任务的平均耗时 |
| 测量方法 | `cargo bench` 基准测试 |
| 当前目标 | < 500ms |
| 现状基线 | 待测量 |

**改进方向**:
- 缓存常用类型信息
- 优化 AST 解析
- 并行化独立任务

---

### 3. 测试覆盖率 (Test Coverage)

| 属性 | 值 |
|------|-----|
| 定义 | 被测试代码行数 / 总代码行数 |
| 测量方法 | `cargo tarpaulin` |
| 当前目标 | ≥ 80% |
| 现状基线 | 待测量 |

**改进方向**:
- 增加集成测试
- 补充边界条件测试
- 消除死代码

---

### 4. CLI 响应时间 (CLI Response Time)

| 属性 | 值 |
|------|-----|
| 定义 | 用户输入到首字符输出的延迟 |
| 测量方法 | 手动/自动化测试 |
| 当前目标 | < 100ms |
| 现状基线 | 待测量 |

**改进方向**:
- 延迟加载非必要模块
- 优化启动时间
- 流式输出首字符

---

## 指标仪表盘

```bash
# 运行基准测试
cargo bench

# 生成覆盖率报告
cargo tarpaulin --output --tests

# 测试 CLI 响应
time cargo run -- synthesize --code "fn test() {}"
```
