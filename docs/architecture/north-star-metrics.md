# 北极星指标

**当前版本**: 0.1.0
**更新日期**: 2026-08-04

---

## 概述

北极星指标是衡量 AutoHarness 项目成功的核心指标。所有 AI 决策和开发工作都必须围绕这些指标展开。

---

## 核心指标

### 1. 代码合成成功率 (Synthesis Success Rate)

| 属性 | 值 |
|------|-----|
| 定义 | 成功合成的测试用例数 / 总请求数 |
| 测量方法 | 统计 `synthesis` 命令执行结果 |
| 当前目标 | ≥ 85% |
| 现状基线 | 待测量 |

**改进方向**:
- 优化 LLM prompt 模板
- 增加更多合成策略
- 改进错误处理和回退机制

---

### 2. 平均合成时间 (Average Synthesis Time)

| 属性 | 值 |
|------|-----|
| 定义 | 单次合成任务的平均耗时 |
| 测量方法 | `cargo bench` 基准测试 |
| 当前目标 | < 500ms |
| 现状基线 | 待测量 |

**改进方向**:
- 缓存常用类型信息
- 优化 AST 解析
- 并行化独立任务

---

### 3. 测试覆盖率 (Test Coverage)

| 属性 | 值 |
|------|-----|
| 定义 | 被测试代码行数 / 总代码行数 |
| 测量方法 | `cargo tarpaulin` |
| 当前目标 | ≥ 80% |
| 现状基线 | 待测量 |

**改进方向**:
- 增加集成测试
- 补充边界条件测试
- 消除死代码

---

### 4. CLI 响应时间 (CLI Response Time)

| 属性 | 值 |
|------|-----|
| 定义 | 用户输入到首字符输出的延迟 |
| 测量方法 | 手动/自动化测试 |
| 当前目标 | < 100ms |
| 现状基线 | 待测量 |

**改进方向**:
- 延迟加载非必要模块
- 优化启动时间
- 流式输出首字符

---

## 指标仪表盘

```bash
# 运行基准测试
cargo bench

# 生成覆盖率报告
cargo tarpaulin --output --tests

# 测试 CLI 响应
time cargo run -- synthesize --code "fn test() {}"
```

---

## 5. Loop Readiness Score（Loop 系统健康度）

| 属性 | 值 |
|------|-----|
| 定义 | `loop-doctor.sh` 10 维综合评分 |
| 测量方法 | `bash scripts/loop-doctor.sh` 或 `cargo run -- loop doctor .` |
| 当前目标 | ≥ 80（解锁 L3 候选 Pattern） |
| 现状基线 | 88 (R3，2026-08-06 Phase 1 完成) |

**改进方向**:
- 维持 10 个配置文件存在性
- 持续累积 L1 runs（每 24h 至少 1 条）
- 守住 maker/checker 分离的 HarnessType 引用

---

## 6. L1 Accuracy（State.md 人工 review 准确率）

| 属性 | 值 |
|------|-----|
| 定义 | 人工 review 确认 STATE.md 中"对"的比例 |
| 测量方法 | `bash scripts/loop-accuracy.sh`（解析 STATE.md 的 `## Accuracy Tracking` 段） |
| 当前目标 | ≥ 80%（解锁 L2 候选 Pattern） |
| 现状基线 | 待 Phase 2 启动后累积（14 天 + ≥ 10 runs） |

---

## 7. Token 效率（实际 / 预算）

| 属性 | 值 |
|------|-----|
| 定义 | 实际 token 开销 / `loop-budget.md` 预算 |
| 测量方法 | 每次 run 检查；80% 降级 L1，100% 退出，150% 红线 |
| 当前目标 | ≤ 80%（强制降级） |
| 现状基线 | 0（Phase 1 未跑任何 loop） |

---

## 8. 信噪比（需人介入 / 总发现项）

| 属性 | 值 |
|------|-----|
| 定义 | 需人介入的发现项数 / 总发现项数 |
| 测量方法 | `loop-accuracy.sh` 解析 |
| 当前目标 | ≤ 25%（越低越好） |
| 现状基线 | 待 Phase 2 累积 |
